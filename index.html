For a mixed-size carton: tick "Mixed sizes", leave Size blank, and type the breakdown as e.g. 20 x Small, 30 x Medium. If each carton on this line has a different mix, separate them with | — e.g. 10 x XS, 15 x S | 20 x M, 15 x L, 5 x XL makes carton 1 show the first mix and carton 2 show the second, and "No. of Cartons" is worked out from how many you listed. If they're all the same mix, skip the | and just set "No. of Cartons" as normal.

Matches the "5.2 Outer Carton Label" layout: title, PO Number, Style Ref / Description / Colour / Size / Supplier table, Box X of Y, and Carton Unit Qty. For mixed-size cartons, a "MIXED SIZES" banner is added and the qty box lists the size breakdown instead of a single number, per your example.
